# Local datasets (not distributed)

Download the 2019 and 2023 International Women's World Cup **Match CSV**, **Teams CSV**, and **Players CSV** exports from [FootyStats](https://footystats.org/international/womens-world-cup/datasets).

The original data exports are not included. See the project [README](../README.md#data-source-and-downloads) for the six expected file paths.
